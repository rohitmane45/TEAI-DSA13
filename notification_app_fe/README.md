# Notification System Frontend

This folder will contain the Frontend application for the Priority Inbox notification system.

## Planned Stack
- **Framework:** Next.js (TypeScript preferred)
- **Styling:** Vanilla CSS or Material UI
- **Design Principles:** Sleek, micro-animations, glassmorphism dashboard, dynamic real-time priority updates.

## Guidelines Compliance
- Strictly adheres to the evaluation rules: no external packages for priority algorithms, pure Material UI/Vanilla CSS for styling, fully responsive layouts for both mobile and desktop.
